# Contract Insights Copilot

Build a creative, highly efficient business intelligence solution named "Dynamic Client-Contract KPI Copilot" that ingests complex legal/business contracts to generate multi-tenant pipelines and custom KPI dashboards.

- Features: Contract text parser simulation, automated multi-tenant config generator, and dynamic KPI visualizer.

- UI & Theme: Executive-level modern SaaS dashboard featuring an accessible Dark, Light, and System Default theme toggle.

- Requirements: Fully working file upload/input simulation, interactive dashboard widgets, zero errors, and robust mock database state.
